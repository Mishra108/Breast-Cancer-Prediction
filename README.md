# 🩺 Breast Cancer Prediction System

A Machine Learning web app that predicts whether a breast tumor is:

- Malignant
- Benign

Built using Python, Scikit-learn, and Streamlit.

---

# 🌐 Live Demo

🔗 [Click Here to Open App](https://breastcancerpredicti0n.streamlit.app/)

---

# 🚀 Features

- Breast Cancer Prediction
- Streamlit Web UI
- Multiple ML Models
- Model Comparison
- Saved Trained Model

---

# 🧠 Models Used

- Logistic Regression
- SVM
- Random Forest
